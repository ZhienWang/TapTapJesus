# TapTapBaby: Privacy Policy

_Last updated: September 30, 2026_

Tap Tap Baby is a desktop companion. The on-screen character slaps its manger, keyboard or desk whenever you type or click, and it keeps a running count of those taps.

## What the app observes

To animate the character and keep its counters, the app listens for keyboard and mouse activity system-wide while it is running. It uses that activity only to:

- add one to the **keystroke** counter when a key is pressed;
- add one to the **left click** or **right click** counter when a mouse button is pressed;
- add to a **mouse distance** total, worked out from how far the pointer moves;
- add one to the current character's own tap counter, which unlocks new characters as you level up;
- choose which hand to animate (keys on the left half of the keyboard use the left hand).

To show your **top apps**, the app also checks once a second which program's window is in the foreground, and adds up the **time used** for each program. Only programs you leave checked under **Choose apps to track** are counted. Time isn't counted when you've been away for more than two minutes. For each program it keeps only the program's name (for example "Visual Studio Code" / `Code.exe`), the total time used and a tap count. It never reads window titles, documents, web addresses or anything shown on screen.

**The app never records which keys you press, what you type, or where you click.** It keeps no text, passwords, screenshots or window contents. Only the totals above are kept.

## What is stored

The counters, each character's tap count and which characters you've unlocked, the per-program usage totals and tracking choices, the character's on-screen position, its size and your chosen character are saved in a small file on your own computer, in the app's local data folder. Nothing else is stored.

## What is shared

Nothing. The app has no accounts, analytics, advertising or telemetry, and it sends no data over the internet.

The only network activity happens if you choose **Donate with PayPal**. That opens PayPal's website in your web browser, and PayPal's own privacy policy applies there.

## Deleting your data

Choose **Reset** in the app's Details panel to set the keystroke, click, mouse-distance and app-time totals back to zero. Character levels and unlocks are kept, so you don't lose characters you've earned. Uninstalling the app removes its local data folder, including levels and unlocks.
